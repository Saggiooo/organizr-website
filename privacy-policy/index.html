Privacy Policy of the Organizr App

1. Data controller

The data controller is Allpromotion di Massimo Policano, Via Bruno Bottau 4, Castenaso (BO), Italy. Email: info@wonder-web.it.

2. Type of application

Organizr is a desktop application built with Tauri technology. The app works in local (offline) mode by default: all data entered by the user is stored exclusively on the user's device. An optional Sync feature is available: if explicitly activated by the user, data is backed up to our secure server located in the European Union. Sync is disabled by default and must be enabled manually.

3. Data processed

3.1 Locally stored data (default mode)

By default, the app stores exclusively on the user's device: tasks and activities (kanban), subscription data, nutrition information, workout data, and API keys manually entered by the user.

In offline mode, this data is not transmitted to the controller, not shared with third parties, and not synchronized to any external server.

3.2 Cloud sync data (optional)

If the user explicitly activates the Sync feature, the data listed in section 3.1 is encrypted end-to-end and transmitted to our server located in the European Union (EU). Data is stored in encrypted form and is not accessible in plain text by the controller or any third party.

The legal basis for this processing is the user's explicit consent, given at the time of activating the Sync feature. The user can disable Sync at any time from the app settings, which stops any further transmission and allows requesting deletion of cloud data by contacting us at info@wonder-web.it.

3.3 Technical connection data

The app may make limited network connections to check for updates. During this operation, IP address, technical device information and app version may be processed. Such data is used solely to provide updates and ensure the security and correct operation of the app.

Google Fonts: the app uses fonts provided by Google. This may involve a connection to Google's servers, with possible transmission of IP address and browser/webview information.

External API integrations (FatSecret, Hevy): the app allows the user to manually enter API credentials for third-party services such as FatSecret and Hevy. For FatSecret, the user may authenticate via an external browser.

Important: Organizr does not manage or store data on its own servers. All data obtained via APIs remains exclusively local. Data processing by these services is governed by their respective privacy policies.

4. Purposes of processing

Data is processed to enable use of the app's features, allow update checks, and integrate external services at the user's request.

5. Legal basis

Processing is based on: performance of a service requested by the user, legitimate interest (security, updates), and consent for external API integrations, where applicable.

6. Data retention

In offline mode, user data is stored exclusively on the local device with no automatic backups on the controller's servers. The user can manually export/import data.

If Sync is enabled, data is retained on the EU server in encrypted form until the user disables Sync or requests deletion. The user can request complete removal of cloud data by writing to info@wonder-web.it.

7. Data sharing

Data is not shared with third parties, except Google for fonts and the external services FatSecret and Hevy if used by the user. If Sync is enabled, encrypted data is stored on the controller's own server in the EU — it is not sold or shared with any third party.

8. User rights

The user can delete data by uninstalling the app or removing local files, export data through the app's features, and request information from the controller via email.

9. Security

The user is responsible for the security of their device and local backups. The controller is not responsible for data loss or unauthorized access to the user's device.

When Sync is active, data is encrypted end-to-end before transmission and stored encrypted on our EU server. The controller cannot read the content of synced data in plain text.

10. Changes

This policy may be updated. Changes will be made available through app updates.

11. Contacts

For any request: info@wonder-web.it.
