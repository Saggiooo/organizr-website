Collega FatSecret a Organizr

Segui questi 3 passaggi per importare in Organizr i dati del tuo diario alimentare. Non serve saper programmare: ti bastano due account e circa 5 minuti.

3 passaggi Circa 5 minuti Nessun codice

Il collegamento in breve

  1. FatSecret PlatformCrea le chiavi API
  2. OrganizrInserisci le due chiavi
  3. FatSecretAccedi e autorizza
!

Prima di iniziare

Ti serviranno due account diversi

L’account di FatSecret Platform serve solo a creare le chiavi API. Alla fine dovrai invece accedere con il tuo account personale FatSecret, cioè quello che usi nell’app per registrare pasti e calorie.

01Crea l’account 02Ottieni le chiavi 03Autorizza Organizr
01

Account sviluppatore

Crea un account su FatSecret Platform

Apri la piattaforma per sviluppatori di FatSecret e registrati. Questo account ti permetterà di generare le credenziali necessarie al collegamento con Organizr.

Apri FatSecret Platform

Hai già un account sulla piattaforma? Accedi e passa direttamente al punto 2.

02

Credenziali API

Attiva “REST API OAuth 1.0 Credentials”

Dopo l’accesso a FatSecret Platform, apri Impostazioni, poi entra in API KEYS. Cerca la sezione chiamata esattamente REST API OAuth 1.0 Credentials e attivala.

Impostazioni API KEYS REST API OAuth 1.0

Da salvare

Copia entrambe le chiavi

  • Consumer Key
  • Consumer Secret

Conservale in un posto sicuro. Non pubblicarle e non condividerle con altre persone.

03

Dentro Organizr

Inserisci le chiavi e clicca “Autorizza”

Apri in Organizr la sezione dedicata a FatSecret. Incolla la Consumer Key e la Consumer Secret nei rispettivi campi, quindi clicca su Autorizza.

Attenzione all’account che usi

Si aprirà FatSecret nel browser. Qui devi accedere con l’account della vera app FatSecret, quello che contiene il tuo diario alimentare. Non usare l’account di FatSecret Platform creato al punto 1.
