Privacy Policy dell'app Organizr

1. Titolare del trattamento

Il Titolare del trattamento dei dati è Allpromotion di Massimo Policano, Via Bruno Bottau 4, Castenaso (BO), Italia. Email: info@wonder-web.it.

2. Tipologia di applicazione

Organizr è un'applicazione desktop sviluppata con tecnologia Tauri. L'app funziona in modalità locale (offline) per impostazione predefinita: tutti i dati inseriti dall'utente sono salvati esclusivamente sul dispositivo dell'utente. È disponibile una funzione opzionale di Sync: se attivata esplicitamente dall'utente, i dati vengono salvati su nostri server sicuri situati nell'Unione Europea. La sincronizzazione è disattivata per impostazione predefinita e deve essere abilitata manualmente.

3. Dati trattati

3.1 Dati salvati localmente (modalità predefinita)

Per impostazione predefinita, l'app memorizza esclusivamente sul dispositivo dell'utente: attività e impegni (kanban), dati relativi ad abbonamenti, informazioni alimentari, dati relativi agli allenamenti e chiavi API inserite manualmente dall'utente.

In modalità offline, questi dati non vengono trasmessi al Titolare, non vengono condivisi con terze parti e non vengono sincronizzati su alcun server esterno.

3.2 Dati sincronizzati in cloud (opzionale)

Se l'utente attiva esplicitamente la funzione Sync, i dati elencati nella sezione 3.1 vengono cifrati end-to-end e trasmessi a nostri server situati nell'Unione Europea (UE). I dati sono conservati in forma crittografata e non sono accessibili in chiaro dal Titolare né da terze parti.

La base giuridica di questo trattamento è il consenso esplicito dell'utente, espresso al momento dell'attivazione della funzione Sync. L'utente può disattivare la sincronizzazione in qualsiasi momento dalle impostazioni dell'app, interrompendo ogni ulteriore trasmissione, e può richiedere la cancellazione dei dati cloud contattando il Titolare a info@wonder-web.it.

3.3 Dati tecnici di connessione

L'app può effettuare connessioni di rete limitate per il controllo aggiornamenti. Durante questa operazione possono essere trattati indirizzo IP, informazioni tecniche del dispositivo e versione dell'app. Tali dati sono utilizzati esclusivamente per fornire aggiornamenti e garantire la sicurezza e il corretto funzionamento dell'app.

Google Fonts: l'app utilizza font forniti da Google. Questo può comportare una connessione ai server di Google, con possibile trasmissione di indirizzo IP e informazioni del browser/webview.

Integrazione API esterne (FatSecret, Hevy): l'app consente all'utente di inserire manualmente credenziali API per servizi di terze parti come FatSecret e Hevy. Nel caso di FatSecret, l'utente può effettuare l'autenticazione tramite browser esterno.

Importante: Organizr non gestisce né memorizza dati sui propri server. Tutti i dati ottenuti tramite API restano esclusivamente in locale. Il trattamento dei dati da parte di tali servizi è regolato dalle rispettive privacy policy.

4. Finalità del trattamento

I dati sono trattati per consentire l'utilizzo delle funzionalità dell'app, permettere il controllo aggiornamenti e integrare servizi esterni su richiesta dell'utente.

5. Base giuridica

Il trattamento si basa su: esecuzione di un servizio richiesto dall'utente, legittimo interesse (sicurezza, aggiornamenti) e consenso per integrazioni API esterne, ove applicabile.

6. Conservazione dei dati

In modalità offline, i dati dell'utente sono conservati esclusivamente sul dispositivo locale, senza backup automatici su server del Titolare. L'utente può effettuare manualmente esportazione/importazione dei dati.

Se la funzione Sync è attiva, i dati sono conservati in forma crittografata sul server UE del Titolare fino alla disattivazione della sincronizzazione o alla richiesta di cancellazione. L'utente può richiedere la rimozione completa dei dati cloud scrivendo a info@wonder-web.it.

7. Comunicazione dei dati

I dati non vengono comunicati a terzi, salvo Google per i font e i servizi esterni FatSecret e Hevy se utilizzati dall'utente. Se la funzione Sync è attiva, i dati crittografati sono conservati sul server del Titolare nell'UE — non vengono venduti né condivisi con terze parti.

8. Diritti dell'utente

L'utente può cancellare i dati eliminando l'app o i file locali, esportare i dati tramite le funzioni dell'app e richiedere informazioni al Titolare via email.

9. Sicurezza

L'utente è responsabile della sicurezza del proprio dispositivo e dei backup locali. Il Titolare non è responsabile per perdita di dati o accessi non autorizzati al dispositivo dell'utente.

Quando la funzione Sync è attiva, i dati vengono cifrati end-to-end prima della trasmissione e conservati in forma crittografata sul nostro server nell'UE. Il Titolare non può leggere il contenuto dei dati sincronizzati in chiaro.

10. Modifiche

La presente policy può essere aggiornata. Le modifiche saranno rese disponibili tramite aggiornamenti dell'app.

11. Contatti

Per qualsiasi richiesta: info@wonder-web.it.
