Scarica Organizr per Windows.

Scarica il programma di installazione e segui i passaggi qui sotto per completare l'installazione. Organizr è un'app nuova, quindi Windows potrebbe mostrare un avviso di sicurezza — è completamente sicuro procedere.

1

Scarica il programma di installazione

Clicca il pulsante qui sotto per scaricare il programma di installazione di Organizr per Windows. Il file è un setup .exe — eseguilo dopo il download.

Prima di eseguirlo: Windows mostrerà un avviso di sicurezza SmartScreen (vedi sotto). È normale per le app nuove — segui i passaggi 2 e 3 per procedere.

Scarica per Windows
2

Avviso Windows SmartScreen

Quando esegui il programma di installazione, Windows Defender SmartScreen potrebbe mostrare un avviso con scritto "Windows ha protetto il PC". Questo accade perché Organizr è un'app nuova e non ha ancora accumulato una reputazione sufficiente con Microsoft — non perché sia pericolosa.

Clicca su "Ulteriori informazioni" nella finestra di dialogo per visualizzare l'opzione successiva.

3

Clicca "Esegui comunque"

Dopo aver cliccato "Ulteriori informazioni", apparirà il pulsante "Esegui comunque" in fondo alla finestra. Cliccalo per avviare l'installazione.

Organizr si installerà in pochi secondi. Nessun account richiesto — tutti i tuoi dati rimangono sul tuo dispositivo.
